# 倪海厦相学注解

---

## 🌟 1. 项目简介

倪海厦老师于《天纪》中讲授的相学知识博大精深，但因其分布在碎片化的视频中，初学者往往难以窥见全貌，此诚为易学界之一大憾事。

承蒙家师指点，本文对倪师面相知识进行了系统梳理与扩展注释，并辅以大量实证分析，旨在目前大量的倪海厦知识切片上，升华为完整的面相知识体系。

## 🛠 2. 项目特点

### （1）全维度相法体系：

总结了身体五形、动作、言语声音、表情、头部及五官局部（额、眉、眼、鼻、嘴、耳）等相法。

### （2）深度实战批注：

在倪师的知识点之上，加入了笔者的实战心得和家师教诲。

### （3）补充具体例子：

倪海厦老师在视频中虽然给出了很多例子，但是很多例子是缺失的，笔者把这些例子都补充到位，例如：羊眼的示例图片，视频中人物的演示图片。
