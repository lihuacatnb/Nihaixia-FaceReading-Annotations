# 倪海厦相学注解

> 《天纪》面相内容系统化整理工程
>
> 结合原文、案例、实证、图示与术数联动，构建完整倪海厦相学体系

---

## 🌟 1. 内容简介

倪海厦老师于《天纪》中讲授的相学内容博大精深，但因知识碎片化分布在课程与视频之中，后学者往往难以建立完整框架。纵观当下，坊间虽有诸多整理，但大多停留于零散摘录与知识堆砌，缺乏系统化归纳、实证分析与术数联动，因此学习者往往“见树不见林”，难窥相法全貌。

本项目在家师指导下，对倪师面相知识进行了系统梳理与深度注释，并辅以大量实证分析，尝试构建一套较为完整的倪海厦相学框架。

## 📊 2. 项目规模

当前已整理：

- 15 个核心章节
- 100+ 相法条目
- 大量图示、案例与实证分析
- 动态相法体系
- 病气灾气体系
- 手相体系
- 紫微斗数联动分析
- 风水联动内容
- 实战批注与扩展注释

项目仍持续更新中。

## 🛠 3. 项目特点

- **完整体系**：涵盖五行身形，动态神态，面部五官，病气手相等内容。
- **原文注释**：梳理倪师散落知识点并进行深度注释，扩充知识体系。
- **实战案例**：引入大量人物案例、图示与实证分析，增强理解。
